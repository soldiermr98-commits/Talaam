# CHANGELOG.md

## 1.0.0 (اولین نسخه — آماده انتشار)

### محاسبات
- طلای نو: وزن، اجرت (درصد یا تومان بر گرم)، سود طلافروش، مالیات بر ارزش افزوده فقط بر اجرت و سود
- «چند درصد حساب کرده؟»: معکوس‌خوانی اجرت و سود از مبلغ اعلامی، با حکم منصفانه/کمی گران/گران
- دست دوم و آب‌شده: عیارهای ۱۴/۱۸/۲۱/۲۲/۲۴، خرید و فروش با پورسانت، مبدل مظنه به گرم ۱۸ عیار
- حباب سکه: امامی، بهار آزادی، نیم، ربع، گرمی — ارزش ذاتی، مبلغ و درصد حباب، مقایسه قطعات
- مبدل واحدها: گرم، سوت، مثقال صرافی، مثقال شرعی، نخود
- ۵۹ تست واحد برای همه فرمول‌ها، پارس ارقام و رفتار داده خراب

### داده نرخ‌ها
- نمایش فوری آخرین نرخ ذخیره‌شده هنگام کول‌استارت (بدون spinner)
- دریافت پس‌زمینه از فایل JSON با تایم‌اوت ۵ ثانیه؛ خطا بی‌صدا نادیده گرفته می‌شود
- نرخ دستی کاربر تا دریافت موفق بعدی معتبر است + «بازگشت به نرخ خودکار»
- هشدار ملایم برای نرخ قدیمی‌تر از ۶ ساعت
- فایل mock + نمونه Cloudflare Worker و PHP برای اتصال منبع واقعی

### رابط کاربری
- کاملاً فارسی و RTL؛ ارقام فارسی/انگلیسی قابل انتخاب
- تم تیره/روشن/سیستمی؛ کنتراست دسترس‌پذیر در هر دو تم
- فاکتور تصویری ۱۰۸۰px با تاریخ شمسی، حروف مبلغ و کد پیگیری + ذخیره/اشتراک‌گذاری
- مبدل واحدها در شیت تنظیمات؛ اسکرول‌بار گلس‌مورفیسم سفارشی
- آیکون برند ماشین‌حساب و شمش طلا (هدر، لانچر، اسپلش)

### پلتفرم
- PWA با service worker آفلاین؛ باندل ۸۳۴KB (JS اصلی ۷۳KB gzip)
- Android با Capacitor 8 — package `talam.app`، minSdk 24، فقط مجوز INTERNET
- APK release امضاشده ۳.۸۳MB؛ CI گیت‌هاب برای بیلد خودکار APK/AAB
- بدون وابستگی به گوگل؛ فونت وزیرمتن باندل محلی؛ کاملاً آفلاین
